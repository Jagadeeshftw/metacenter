---
title: Glossary
description: Terms used across the dashboard, API and contracts.
---

| Term | Meaning |
|---|---|
| **PoX-5** | The Bitcoin Staking version of Stacks' Proof of Transfer, deployed as `SP000000000000000000002Q6VF78.pox-5`. |
| **Reward cycle** | 2,100 Bitcoin blocks on mainnet. |
| **Distribution interval** | Half a reward cycle (1,050 Bitcoin blocks). One `calculate-rewards` split per interval. |
| **Calculation height** | The last block of an interval; its distribution is booked to the cycle containing it. |
| **Gross pool** | sBTC received by pox-5 since the previous distribution (`gross-accrued-rewards`). |
| **Bond** | A fixed-term position with a target rate; paid before STX-only stakers. |
| **stx-value-ratio** | A bond parameter that sets its place in the payout order (higher is paid first). |
| **Target / obligation** | What a bond is owed per interval: `shares × target-rate ÷ 10000 ÷ 50`. The sum over bonds is the obligation. |
| **Tranche 1 / Tranche 2** | SIP terms for bonds (paid first) and STX-only stakers (paid from the remainder). |
| **Reserve** | Receives 15% of the remainder after bonds. Accrual-only under the current contract. |
| **Coverage** | Gross pool ÷ obligation. |
| **Headroom** | How far the pool can fall before bond yield is impaired: `1 − 1/coverage`. |
| **Hypothetical cover** | Reserve ÷ (2 × obligation per interval), in cycles. A size comparison, not a payout schedule. |
| **Rewards per token (rpt)** | pox-5's cumulative per-sat / per-uSTX reward counter for a cycle. |
| **Sortition** | A Bitcoin block in which a Stacks miner won a tenure. Blocks without one pay nothing into the pool. |
| **Provenance** | onchain, mirrored or hypothetical. See [Provenance labels](/docs/concepts/provenance). |
